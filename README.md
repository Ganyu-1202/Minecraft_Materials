# Minecraft_Materials

Mode Materials for Minecraft Java Edition

## Overview

This mod provides enhanced versions of original building blocks, weakened versions of some materials.

Do you feel your residence is not strong enough? Do you want more types of building materials? Do you need more stepping
blocks? This mod can provide you with a variety of blocks and items with different characteristics.

This mod brings the Firefly Bush from later official versions, allowing it to exist in version 1.20, and enables the
crafting of Glowstone Dust from Firefly Bushes.

## World Generation

This mod adds world generation for Dissolved Stone, "Six-Phase Ice", and Firefly Bushes:

- Dissolved Stone generates in lower-level dripstone caves and near dripstone clusters.
- "Six-Phase Ice" generates on and under the water of icebergs in cold biomes.
- Firefly Bushes generate on Grass Blocks in the Overworld and can be spread using Bone Meal.
